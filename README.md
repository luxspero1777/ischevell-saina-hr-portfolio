## 🚀 Panduan Publish ke GitHub & GitHub Pages

Repositori ini sudah dioptimalkan dan siap 100% untuk langsung dipublikasikan ke GitHub dan GitHub Pages secara otomatis.

### Langkah 1: Buat Repositori Baru di GitHub
1. Buka [GitHub](https://github.com) dan login ke akun Anda.
2. Klik tombol **"+"** di pojok kanan atas, lalu pilih **New repository**.
3. Beri nama repositori (contoh: `ischevell-saina-portfolio` atau `solusikerjakita`).
4. Atur ke **Public**.
5. Jangan centang "Add a README file" (karena file ini sudah tersedia).
6. Klik **Create repository**.

### Langkah 2: Hubungkan & Push Kode dari Komputer Anda
Buka terminal pada folder proyek ini, lalu jalankan perintah berikut:

```bash
# Inisialisasi git (jika belum ada)
git init

# Tambahkan seluruh file ke staging
git add .

# Buat commit pertama
git commit -m "feat: initial commit ready for github pages"

# Ubah branch utama menjadi main
git branch -M main

# Hubungkan ke repository GitHub Anda (ganti USERNAME dan REPO_NAME)
git remote add origin https://github.com/USERNAME/REPO_NAME.git

# Push kode ke GitHub
git push -u origin main
```

### Langkah 3: Aktifkan GitHub Pages Otomatis
Repositori ini sudah dilengkapi file workflow otomatis di `.github/workflows/deploy.yml`.

1. Buka repositori Anda di GitHub.
2. Klik tab **Settings** di menu atas repositori.
3. Pada sidebar kiri, klik **Pages** (di bawah bagian *Code and automation*).
4. Pada bagian **Build and deployment** > **Source**, pilih opsi:  
   👉 **GitHub Actions**
5. Selesai! GitHub Actions akan otomatis menjalankan build Vite dan mempublikasikan website Anda.
6. Dalam waktu 1–2 menit, website Anda akan aktif dan dapat diakses di:  
   `https://USERNAME.github.io/REPO_NAME/`

## 💻 Menjalankan Proyek Secara Lokal (Local Development)

Jika Anda ingin menguji atau mengembangkan website ini di komputer lokal:

### 1. Prasyarat
- Pastikan [Node.js](https://nodejs.org/) versi 18 atau lebih baru sudah terpasang.

### 2. Instalasi Dependensi
```bash
npm install
```

### 3. Menjalankan Server Pengembangan (Dev)
```bash
npm run dev
```
Buka browser di `http://localhost:3000` untuk melihat preview interaktif secara langsung.

### 4. Build untuk Produksi
```bash
npm run build
```
Hasil build yang teroptimasi, ter-minifikasi, dan ter-bundle akan dibuat di folder `dist/`.

### 5. Preview Hasil Build
```bash
npm run preview
```

## 🛠️ Cara Mengubah Konten & Foto

Seluruh data konten bersifat modular dan dapat diubah dengan mudah tanpa perlu menyentuh komponen UI:

- **Mengubah Teks Profil, Pengalaman Kerja, Keahlian, dan Lowongan:**  
  Buka file `src/data/hrData.ts`. Di file ini Anda dapat memperbarui:
  - `CLIENT_PROFILE`: Nama, tagline, kontak WhatsApp, email, domisili.
  - `CAREER_EXPERIENCES`: Menambah atau mengedit riwayat pekerjaan, periode, dan pencapaian.
  - `ACTIVE_JOBS`: Menambah atau mengubah daftar lowongan kerja aktif di SolusiKerjaKita.
  - `SKILL_CATEGORIES`: Mengubah matriks keahlian.
  - `GALLERY_ITEMS`: Mengatur dokumentasi foto kegiatan.

- **Mengganti / Menambah Foto:**  
  1. Simpan file foto baru Anda di folder `src/assets/images/` dan `public/images/`.
  2. Buka file `src/data/assets.ts`, tambahkan import file foto baru tersebut.
  3. Kaitkan foto ke item yang diinginkan di `src/data/hrData.ts`.
